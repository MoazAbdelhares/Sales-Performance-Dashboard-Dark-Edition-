# Sales-Performance-Dashboard-Dark-Edition-

This project features a high-impact, interactive Sales Analytics Dashboard designed with a modern Dark Mode interface. It provides a comprehensive analysis of retail performance, enabling stakeholders to monitor key financial metrics, regional growth, and product category trends. The dashboard transforms raw transactional data into actionable business intelligence.

 Key Insights (Findings)
Revenue Powerhouse: The Technology category is the primary revenue driver, contributing $836,154 (approx. 36% of total sales).

Geographic Dominance: The West Region is the top-performing territory ($725,458), with California alone generating $457,688—more than any other state.

Product Mix: Sub-category analysis reveals that Phones (26%) and Chairs (25%) are the most significant contributors to the product portfolio.

Financial Health: While Total Sales reached $2.29M, the dashboard highlights a $180,504 return value, signaling an area for potential operational improvement.

Customer Engagement: A solid base of 793 unique customers generated over 5,000 orders, showing strong brand loyalty and repeat purchasing behavior.

 Technical Highlights
KPI Tracking: Real-time visualization of Total Sales, Net Sales, Returns, Discounts, and COGS.

Data Modeling: Implementation of DAX measures for complex calculations (e.g., Net Sales = Sales - Returns - Discounts).

Advanced Visuals: Use of dual-axis charts to compare Sales vs. Quantity over time (2014-2017).

Interactivity: Fully functional slicers for City, Person, Return Status, and Category for granular data exploration.

 لوحة بيانات تحليل المبيعات (النسخة المظلمة)
 نظرة عامة على المشروع
يقدم هذا المشروع لوحة بيانات (Dashboard) تفاعلية ومتقدمة لتحليل المبيعات، مصممة بواجهة "Dark Mode" عصرية. توفر اللوحة رؤية شاملة لأداء العمليات التجارية، مما يسمح لأصحاب القرار بمراقبة المؤشرات المالية الرئيسية، النمو الإقليمي، وتوجهات فئات المنتجات. يهدف المشروع إلى تحويل البيانات الخام إلى رؤى تجارية قابلة للتنفيذ.

 أهم الرؤى والنتائج (Insights)
المحرك الرئيسي للأرباح: تصدرت فئة التكنولوجيا (Technology) المبيعات بقيمة 836,154 دولار (حوالي 36% من إجمالي المبيعات).

السيطرة الجغرافية: تعد المنطقة الغربية (West) هي الأفضل أداءً بقيمة 725,458 دولار، وتبرز ولاية كاليفورنيا كأكبر مساهم فردي بقيمة 457,688 دولار.

مزيج المنتجات: كشف تحليل الفئات الفرعية أن الهواتف (26%) والكراسي (25%) هما الأكثر تأثيراً في محفظة المنتجات.

الصحة المالية: رغم وصول المبيعات إلى 2.29 مليون دولار، توضح اللوحة وجود مرتجعات بقيمة 180,504 دولار، مما يشير إلى فرصة لتحسين العمليات وتقليل الفاقد.

تفاعل العملاء: قاعدة بيانات قوية تضم 793 عميلاً فريداً قاموا بإنشاء أكثر من 5000 طلب، مما يعكس ولاءً جيداً للعلامة التجارية.

 المميزات التقنية
تتبع مؤشرات الأداء (KPIs): عرض فوري لإجمالي المبيعات، صافي المبيعات، المرتجعات، الخصومات، وتكلفة البضاعة المباعة.

نمذجة البيانات: استخدام معادلات DAX لحساب القيم المعقدة (مثل: صافي المبيعات = الإجمالي - المرتجعات - الخصومات).

رسوم بيانية متقدمة: استخدام مخططات المحاور المزدوجة لمقارنة حجم المبيعات مقابل الكمية عبر السنوات (2014-2017).

تفاعلية كاملة: إضافة فلاتر (Slicers) للمدن، المناديب، حالة المرتجعات، والفئات لتسهيل استكشاف البيانات بدقة.
